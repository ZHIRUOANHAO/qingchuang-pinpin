# 轻创拼拼

轻创拼拼是一个原生微信小程序工程，用 3D 商业星球与 DNA 双螺旋呈现真实商业案例的关键结构。本版采用“纯前端、本地预置、全量免费”的发布策略，不接入外部 AI、文件上传、云登录、会员订单、支付或广告。

当前体验主链为：

`选择预置案例 -> 查看商业 DNA -> 阅读阶段资产卡 -> 加入画布 -> 形成验证方案`

商业阶段固定为：

`卖点定位 -> 引流获客 -> 种草教育 -> 转化成交 -> 收款 -> 产品交付 -> 复购裂变`

## 快速开始

### 网页预览

双击项目根目录的 `start-preview.cmd`，脚本会启动本地预览并打开浏览器。默认地址为 `http://127.0.0.1:4173/preview/`；启动日志保存在 `output/preview/`。该地址只用于本机验收，不代表产品已经上线。

### 微信小程序

1. 在微信开发者工具中导入项目根目录，而不是 `preview/`。
2. 本地开发可使用测试 AppID；正式上传必须替换为运营主体名下的正式 AppID。
3. 在开发者工具中执行“工具 -> 构建 npm”。
4. 编译后逐页检查首页、案例库、案例演示、画布和我的五个 Tab。

本版运行只读取小程序包内的预置案例，不需要 API 密钥、云开发环境、合法域名或支付商户配置。正式发布仍需完成主体认证、备案、服务类目与隐私配置。

详细配置见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)，发布阻塞项见 [docs/上架问题清单.md](docs/上架问题清单.md)，逐项验收见 [docs/RELEASE-CHECKLIST.md](docs/RELEASE-CHECKLIST.md)。

## 当前发布版能力

- 案例库包含 100 条预置案例，全部免费开放，不再区分免费与付费目录。
- “案例演示”只允许选择内置案例；无文本、网页、图片或 PDF 上传入口，也不会调用外部 AI 服务。
- 案例详情用七阶段商业链路展示 DNA 节点，并提供对应的阶段资产卡。
- 案例可加入本地画布，形成只保存在当前设备上的项目与验证记录。
- 账号区域不发起微信云登录；会员、订单、购买、支付与海报入口均不属于本版用户路径。
- 广告开关保持关闭，广告位不会进入本版核心体验。
- 隐私政策、用户协议等法律页面已经建立，但正式主体名称、AppID、备案信息、服务类目和真实支持邮箱仍需发布主体确认并回填。

## 数据与隐私边界

- 所有演示内容均随包预置，运行时不向外部 AI、内容解析或文件处理服务发送数据。
- 本版没有图片、文档或网址上传流程，也不需要配置 `uploadFile` / `downloadFile` 合法域名。
- 本地收藏、画布与验证进度只保存在当前设备；卸载、清理缓存或更换设备后可能丢失。
- 案例来源、证据边界和风险提示应以界面显示内容为准；案例只作结构化学习参考，不构成收益承诺。

## 目录与发布路径

- `miniprogram/`：当前原生小程序发布代码。
- `preview/`：浏览器本地预览。
- `tests/`：结构、数据与交互校验。
- `docs/`：开发、隐私、审核与发布说明。
- `scripts/`：项目辅助脚本。
- `cloudfunctions/`：历史服务端脚手架，当前发布版未启用、无需部署，也不属于本版发布路径。

仓库中可能仍保留会员、订单、支付、海报、云登录或旧 AI 流程相关的 legacy 页面与服务文件，用于历史记录或未来评估；它们在当前导航和正式发布路径中均不启用。不要因为这些脚手架仍在仓库中，就把它们申报为本版实际功能。
