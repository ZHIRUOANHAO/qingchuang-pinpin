# 首页星球体验优化

## 范围与分工

本轮聚焦“从星球发现案例、顺畅点选和阅读”，不新增登录、付费、云端评论或其他无关能力。保留已有五圈同心共面轨道、100 条案例和深蓝金色视觉。

- 总控：原生场景与首页按钮接线、星空背景生命周期、结果整合。
- `preview_orbit_controls` 协作代理：浏览器预览场景与按钮同步。
- `orbit_tests_review` 协作代理：轨迹单元测试、原生 r108 渲染测试。

这里记录的是本会话协作代理分工；本轮没有可用的项目聊天窗口发送工具，未声称已向侧栏的其他窗口发布任务。

## 设计与变化

配色沿用夜空 `#050812`、面板 `#101a2a`、边线 `#344154`、暖金 `#efd892`、说明文字 `#aab4c7`；正文层级和原有字体不变。记忆点仍是中心大球和规整轨道，而不是新增装饰。

1. 五圈同向公转、内快外慢；停止整个轨道盘自动转向，用户调整后的构图不再自行漂移。
2. 移除额外按深度改变球体尺寸的效果，保留真实透视。第三版改为自然行星系统：自然行星色系、程序化球面斑驳、中心暖光造成的明暗分界，行星带极小偏心率与轨道倾角；轨道线降为极淡参考线，不再使用霓虹轨道环、领航星或拖尾。
3. 手指按住时冻结公转；松手后等待 0.8 秒，再渐进恢复。动画按时间推进，避免刷新率不同导致明显速度差。
4. 首页增加暂停/继续和恢复视角，触控区域至少 44 像素。系统减少动态模式保持静态，不通过“继续”强行启动。
5. 小球点选增加容差，不选择被中心球遮住的案例。2D 节能视图也处理主球遮挡和前景小球点选。
6. 页面隐藏、阅读遮罩和组件退出会停止原生渲染回调，回来后不会重复创建动画循环。共用星空背景也补上退出清理与减少动态支持。
7. 案例详情等 DNA 模型保持“竖向让页面滚动、横向旋转、节点打开后停下来阅读”的原有交互，并做回归检查。

## 本地验收

- `npm test`：结构 193 项、100 条案例及 700 张阶段卡、体验逻辑 15 项通过。
- `npm run test:orbits`：轨迹及动画生命周期 12 项通过，包括 30/60/120Hz、暂停、页面隐藏、遮罩与退出清理。
- 原生 UI 20 项通过；原生 r108 Canvas 浏览器测试 145 项通过，覆盖 320/360/430/900 宽度。
- 浏览器全流程 140 项通过，包含搜索、案例、画布与响应式截图。
- `scripts/check-orbit-ui.js`：真实页面控制、像素冻结、拖动缓冲、减少动态与移动端溢出检查；通过后返回实际计数。

截图保存在 `output/playwright/`；原生场景截图位于其 `free-first/` 子目录。

这些结果不替代微信开发者工具正式编译与 iOS/Android 真机复验，本轮未上传、提审或发布。
