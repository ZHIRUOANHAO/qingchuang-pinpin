# 当前产品范围

轻创拼拼是一个本地商业案例学习与验证工具。3D 星球用于发现案例，商业 DNA 用于理解阶段，资产卡和画布用于把理解转成可检查的行动。

## 当前版本验证目标

1. 用户能否从预置案例中复述一条完整交易链路。
2. 用户能否分清卖点、获客、种草、成交、收款、交付与复购七个阶段。
3. 用户能否识别每个阶段的资产、成本、难度与风险，而不是只看到抽象图形。
4. 用户能否把案例内容放入本地画布，形成 7 天验证动作并记录证据。

当前最小闭环为：

`选择预置案例 -> 阅读交易说明 -> 查看七阶段 DNA -> 打开阶段资产卡 -> 加入本地画布 -> 执行 7 天验证 -> 继续 / 调整 / 暂停`

## 当前明确包含

- 100 条包内预置案例，全部免费阅读全文。
- 案例搜索、筛选、收藏、来源与证据边界。
- 七阶段商业 DNA、阶段资产卡、画布与验证记录。
- 当前设备上的本地保存与清除。
- 隐私保护指引、用户协议和未成年人保护说明。

## 当前明确不包含

- 自由文本、网页、图片或 PDF 输入与上传。
- 外部 AI 或任何智能生成、分析、推荐服务。
- 微信登录、云同步和跨设备账户。
- 会员、订单、购买、支付、广告或激励解锁。
- 对项目结果、成交、收入或利润的保证。

## 当前成功标准

- 100 条案例和 700 张阶段资产卡可稳定打开。
- 用户不登录、不上传、不付费也能完成核心学习与验证流程。
- 首屏和列表不一次性注入全部详情数据，常见设备上交互无阻塞。
- 页面声明、实际数据流和微信审核申报保持一致。
- 使用正式配置通过开发者工具编译、iOS / Android 真机与平台审核。

当前不以付费信号、广告收入、AI 调用量或云端用户数作为本版成功标准。未来商业化能力需要单独立项，不能在本版范围内悄然恢复。
