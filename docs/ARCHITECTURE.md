# 工程架构

## 当前发布链路

```text
商业星球首页
-> 100 条免费案例库
-> 预置案例演示 / 案例详情
-> 七阶段商业 DNA 与阶段资产卡
-> 本地画布与 7 天验证
-> 本机收藏、记录和方案
```

当前运行模式固定为 `local_case_library`。运行时只读取小程序包内的数据，不调用外部 AI、内容解析、云登录、订单、支付或广告服务。

## 发布分层

- 页面层：五个 Tab 与案例详情、画布、验证、记录、关于和三份法律说明。
- 组件层：星空、3D / Canvas DNA、节点详情、状态页、安全顶部和隐私弹窗。
- 数据层：100 条案例目录、按需加载的案例正文、七阶段商业节点、画布模块和验证规则。
- 本地状态层：使用微信本机缓存保存收藏、案例演示记录、画布、阶段卡和验证进度。
- 发布预检层：`scripts/release-preflight.mjs` 检查正式 AppID、支持邮箱、路由、网络调用、广告、废弃 API 与风险文案。

## 数据装载策略

- 首页只装载轻量案例摘要，不把 100 条完整正文写入页面初始数据。
- 案例列表分页读取摘要；进入详情后才按 ID 读取完整正文。
- 原始 `nodes` 保留案例的七个编辑问题，用于正文叙事和画布。
- `businessNodes` 把每个案例统一映射为七个商业阶段，用于 DNA 和阶段资产卡。

商业阶段固定为：

`卖点定位 -> 引流获客 -> 种草教育 -> 转化成交 -> 收款 -> 产品交付 -> 复购裂变`

每张阶段资产卡至少包含目标、执行方式、适用赛道、流量/内容/用户/交付资产、成本、难度、风险和可复用点。

## 本地状态与隐私

- 当前版本不要求登录，也不创建云端用户档案。
- 收藏、最近查看、画布、阶段卡和验证进度仅保存在当前设备，清理缓存或换设备后可能丢失。
- 案例演示不接收文字、网页、图片或 PDF，因此没有上传或内容生成链路。
- 设备性能等级和窗口信息只用于选择渲染策略，不用于用户画像或广告。
- 用户可从隐私页面清除本地使用记录。

## 3D 与降级

- 高性能设备使用 `threejs-miniprogram`，低性能设备使用 Canvas 2D 降级视图。
- DNA 色表、节点几何和阶段映射由原生端与网页预览共享，避免两端规则漂移。
- 页面隐藏时暂停动画；组件销毁时释放几何、材质和事件。

## 未启用脚手架

仓库仍保留历史云函数、登录、会员、订单、支付和旧 AI 服务文件，以便追溯旧方案。它们未注册到当前 `app.json` 发布路由，也不应部署或申报为本版功能。未来若恢复其中任一能力，必须重新评估主体资质、服务类目、隐私、内容安全、支付与数据存储要求。

## 发布边界

- 案例是结构化学习资料，不构成投资、法律或收益建议。
- 第三方名称、商标、模板、课程和素材仍归相应权利人所有。
- 正式上架前仍需正式 AppID、备案、服务类目、真实主体信息和支持邮箱，并完成开发者工具编译与真机验收。
