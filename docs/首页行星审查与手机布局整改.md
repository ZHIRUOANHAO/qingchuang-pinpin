# 首页行星审查与手机布局整改

## 审查结论

用户提供的 DSH 版截图需要整改。主要问题不是球体加载失败，而是装饰、布局和交互叠加失控：

1. 56 个几何光扇形成放射尖线；均匀透明的半径 4.2 球壳形成灰色大圆盘。
2. 每颗球的随机近日点方向又旋转了初始等距相位，导致实际位置聚堆；仅检查 phase 的旧测试不能发现这一问题。
3. 每帧重写相机距离覆盖用户缩放，首页星空呼吸还会影响 DNA 模式。
4. 顶部 CTA 使用不等比例列宽；轨道状态与两个默认宽度按钮挤在同一 flex 行，导致说明竖排和按钮裁切。

## 已落地整改

- 移除原生几何放射光扇和巨大透明球壳；大气采用局部边缘衰减，网页同步收敛多层辉光和粒子。
- 保留 100 个案例身份、5 圈轨道、暂停/继续、手势与节点阅读。抵消近日点对显示相位的影响，将偏心率收敛到 1%–2.5%，同时检查最终坐标角距与球体碰撞。
- 停止每帧重写相机，手动缩放不会被自动动画抢回。
- CTA 等宽、48px 同高；暂停和恢复视角等宽、44px 同高。状态独占横排，小屏说明精简但保留证据边界。
- 首页改用明确类名控制组件尺寸、按钮盒模型与禁用态，减少微信 WXSS 不支持的标签/属性选择器带来的差异。

继续工作期间，主球已由其他改动更新为金色线框几何版本。当前整改保留该现行主球，没有将其强行覆盖回之前的蓝色球面。
