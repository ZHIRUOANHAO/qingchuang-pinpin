# 上线与审核前置清单

本清单只针对当前拟发布版本：100 条案例全部免费，案例演示完全读取本地预置数据，不启用外部 AI、上传、云登录、会员订单支付、广告或海报入口。

## 一、发布范围冻结

- [x] 100 条案例全部免费开放，不显示付费筛选、锁定态、售价、购买或会员解锁文案。
- [x] 案例演示只选择内置案例，不提供文本、网址、图片或 PDF 输入与上传。
- [x] 当前用户路径不调用 DeepSeek、Anthropic 或其他外部 AI / 内容解析服务。
- [x] 当前用户路径不发起微信云登录，不依赖云环境或用户集合。
- [x] 会员、订单、购买和支付入口已退出当前导航与发布路径。
- [x] 广告配置保持禁用，不在核心流程展示广告组件。
- [x] 分享海报入口已移除，不再依赖服务端小程序码。
- [x] 隐私政策、用户协议等法律页面已建立。
- [x] `cloudfunctions/` 与 legacy 页面明确为未启用脚手架，不部署、不申报为本版功能。

## 二、必须由发布主体完成

- [ ] 注册或确认正式运营主体，取得可上传的小程序正式 AppID。
- [ ] 将正式 AppID 写入项目配置，并核对项目名称与主体一致。
- [ ] 完成小程序备案。
- [ ] 根据本版真实功能选择并确认服务类目；本版没有生成式 AI、文件上传、交易或广告功能。
- [ ] 在微信公众平台完成隐私保护指引配置，并与小程序内法律页面保持一致。
- [ ] 在法律页和配置中回填正式主体名称、联系方式、备案信息及真实支持邮箱。
- [ ] 确认小程序名称“轻创拼拼”的可用性，以及可能需要的商标或名称证明。
- [ ] 根据实际受众补充未成年人保护与内容投诉处理方式。

## 三、正式配置复核

- [ ] `project.config.json` 使用正式 AppID，不再使用测试号或游客配置。
- [ ] `miniprogram/config/env.js` 中不存在 `support@example.com` 等占位信息。
- [ ] 隐私政策、用户协议、关于页面和后台隐私保护指引中的主体、版本与日期一致。
- [ ] 页面和导航中搜索不到可触达的 AI 输入、上传、云登录、会员、订单、购买、支付或海报入口。
- [ ] 广告总开关仍为关闭，所有广告单元 ID 为空或不进入构建路径。
- [ ] 未启用的 `cloudfunctions/` 和 legacy 页面没有被 `app.json`、导航按钮或运行代码引用。
- [ ] 生产包不要求 `.env` 中存在 AI、云环境、支付或广告密钥。

## 五、内容与合规验收

- [ ] 全库不存在“稳赚、暴利、轻松月入、保证变现”等收益承诺。
- [ ] 案例来源、证据边界、平台规则与风险提示在详情中可见。
- [ ] 全部案例可免费访问，不存在误导性的付费、会员或限时优惠暗示。
- [ ] 家庭认知内容只讨论需求、交换、成本、信任与规则。
- [ ] 法律页面已由正式主体按真实业务复核，且与微信审核申报一致。

- [ ] 微信开发者工具右上角“上传”成功，并填写清晰的版本号与备注。
