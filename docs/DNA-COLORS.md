# DNA 五阶段配色

## 范围与入口

本轮落实用户的“仅针对DNA双链、球体、配对横杆配色规则”，替代此前DNA的金蓝高亮骨架规则，不把全站改成卡通风，也不改案例、评分、账号、支付和广告逻辑。

- 桌面原生工程：`C:\Users\qq345\Desktop\qingchuang-pinpin`，导入这个根目录。
- 唯一色表：`miniprogram/config/dna-theme.js`。
- 共享3D/2D生成器：`miniprogram/utils/dna-renderer.js`。
- 小程序展示：案例详情、AI结果、拼装画布的 `space-scene` 组件。
- 网页DNA预览也读取上述模块，不复制另一份色表。微信不支持这里原先采用的运行时JSON加载方式，2026-08-31迁移为JS，色值保持不变。

## 色彩规则

| 对象 | 颜色 | 处理 |
| --- | --- | --- |
| A · 进攻增长链 | `#A4B1BB` 浅蓝灰 | 低饱和骨架，透明度0.72 |
| B · 防守保障链 | `#B8B1A5` 暖米灰 | 与A链同级，不抢主体 |
| 验证球体 | `#FFF3DA` 奶油白 | 柔和高光、果冻泡泡质感 |
| 冷启动球体 | `#9BD5F3` 天蓝 | 同一组两球同色 |
| 变现跑通球体 | `#A8E5C5` 薄荷绿 | 不采用原模块随机颜色 |
| 稳定运营球体 | `#F4EAA1` 柠檬黄 | 保留柔亮主体 |
| 风控合规球体 | `#D0BCEE` 薰衣草紫 | 不变为高饱和警告色 |
| 配对横杆 | 本组阶段色与中性灰混合 | 中性灰占55%，透明度0.28 |
| 选中引线 | 当前球体阶段色 | 透明度0.32，仅选中球显示 |

骨架半径0.037、横杆半径0.022、球半径0.245。内层高光和极弱外光晕突出泡泡，不靠过曝白光突出。点击不改变阶段色，只轻微放大并显示引线；关闭说明后恢复自转。

## 阶段映射

默认映射为本轮实现采用的展示约定，不代表所有商业案例的客观阶段，也不改变原有 `chain` 业务字段。

| 业务节点 | 默认阶段 |
| --- | --- |
| 曝光、引流 | 冷启动 |
| 种草、转化 | 验证 |
| 成交、交付 | 变现跑通 |
| 复购、裂变、利润 | 稳定运营 |
| 风控 | 风控合规 |

识别顺序：合法的 `node.stage` -> `node.type` 或 `node.id` 的 `nodeStages` 映射 -> `defaultStage`（验证）。调整节点顺序不会改色。新增案例可指定明确stage覆盖默认映射；未知节点暂用默认阶段，后续需内容负责人核对。

## 一处改色

1. 修改配置对象的 `chains.A/B.color` 或 `stages.*.color`。
2. 横杆、配对球、引线和阶段图例自动读取同一色值。
3. 调整 `rung.neutralMix/opacity`、`leader.opacity` 可控制弱化程度，不需要逐条改模型代码。
4. 微信重新编译，网页刷新。不要改 `data/modules.js` 的业务字段来修改DNA颜色。
