## 五、本轮替你排掉的坑（含“你可能没想到的”）

- **断链**：案例页“最近浏览”原本跳一个没注册的页面，真机点击直接报错——已修。
- **假授权**：隐私弹窗用了官方授权按钮样式，但没接 `wx.getPrivacySetting / onNeedPrivacyAuthorization`，点“同意”只写本地缓存；审核若追问“授权对象是谁”会答不上——已改成普通提示。
- **版本号不一致**：关于页写 0.1.0，上传若写 1.0.0，审核员对照会认为版本不符——提审前必须改（列在第四节第 4 步）。
- **基础库冲突**：项目配置 3.12.0 / 私有配置 3.17.4，已被预检判阻塞——已统一。
- **测试误报**：`videos/` 的 9 个 UTF-16 JSON 让 `npm test` 假红——已排除，现在 0 失败。
- **邮箱占位**：隐私页会真的显示“待配置”，这是审核硬伤——填邮箱后自动变成“复制联系邮箱”按钮。
- **上架素材缺失**：AGENTS.md 说素材在 `上架素材/`，实际目录不存在——头像/简介需要补（我可以代生成）。
- **隐私指引后台未配置**：小程序内法律页与后台指引必须一致，否则会被按“隐私政策缺失/不一致”驳回——`02` 里有可粘贴草案。
- **服务类目风险**：本项目是案例学习/商业认知内容，**不要选“教育服务”**（成人培训需办学/人社资质），首选“工具/信息查询”类，详见 `03`。
- **收益表述风险**：`home.wxml:6/9`“普通人·低成本起步优先”“先看低成本试做项目”容易被理解为创业赚钱引导，`08` 给了逐条改写建议（是否改由你定）。
- **审核材料**：本版无账号体系，提审时必须写明“无需登录即可体验全部功能”，否则会按“功能无法体验”驳回。
- **审核时长**：官方不承诺固定时长，普通开发者没有通用加急通道；排期至少留 3 个工作日 + 1 轮被拒修改时间。
