# 08 · 模拟审核预检（审核员视角）

> 用法：提审前一天，找一位**没参与开发的人**按本文第 2 节路线走一遍，逐项打勾；任何一项失败就修完再提审。
> 目标：让审核员在 10 分钟内看懂“这是什么、没有什么、证据在哪、联系方式在哪”。

## 2. 审核员 30 分钟走查路线（按顺序执行）

### Step 0 · 打开小程序（不看说明，纯第一印象）

- 看：名称、头像、简介是否一致；首屏 3 秒内能否看懂“这是案例学习工具”。
- 期望：首屏出现“轻创拼拼”品牌 + “一门生意如何运转？”+ 案例库入口；无“赚钱/暴富/课程”暗示。
- 高风险：`pages/home/home.wxml:8` “普通人 · 低成本起步优先”、`:10` “先看低成本试做项目”——审核员可能理解为创业/赚钱引导。
- 本项目现状：⚠️ 建议改写（见第 5 节）。

### Step 1 · 首页（星球 Tab）

- [ ] 3D 星球能加载、能拖动、点星球能进详情；低端机不白屏。
- [ ] “隐私保护提示”弹窗出现时：能关闭、能看隐私页；按钮文案不误导。
- [ ] 首页“当前 100 条案例附可核对来源…均不代表已审计成交或利润”可见。
- [ ] 广告位不出现空白块；无“即将上线”占位。
- 高风险：`home.js:24` 拒绝隐私后提示“受限功能会再次提示”，但本版无受限功能 → 审核员会追问“受限功能是什么”。
- 现状：⚠️ 文案需改；3D 需真机确认。

### Step 2 · 案例库 Tab

- [ ] 显示 100 条、全部“免费全文”、无付费/会员/锁定态。
- [ ] 搜索、标签筛选、最近浏览、清空、重置可用。
- [ ] 上滑加载更多、下拉刷新不重复/不丢数据。
- [ ] 空结果态有“没有匹配的案例”+“重置筛选”按钮。
- [ ] 每张卡片显示来源状态与核对日期。
- 高风险：若审核员搜到“免费”但页面又有“付费/会员”残留文案（当前 grep 无，但注意 legacy 页面不在路由，不会被看到）。
- 现状：☑ 基本达标。

### Step 3 · 案例详情页（审核重点）

- [ ] 能打开任意案例；返回不丢栈。
- [ ] “公开证据”区显示来源链接、发布方、访问方式、核对日期、证明范围。
- [ ] 七阶段 DNA 可旋转/点节点；纵向滑动页面不卡死（C1 真机项）。
- [ ] 资产卡、成本、合规边界、免责声明可见。
- [ ] 收藏有提示；取消收藏可用。
- [ ] “装配到画布”“查看验证方案”可用。
- 高风险：来源链接点开是 404/需登录 → 审核员会认为证据不可核；索引线索 14 条是否明确标注“仅索引线索”。
- 现状：☑ 结构完整；⚠️ 需抽查链接可用性（07 第 28 条）。

### Step 4 · 案例演示 Tab（原“AI”位置）

- [ ] Tab 名称是“案例演示”，不是“AI 拆解”。
- [ ] 页面明示“无需上传任何材料/不接收文字、网页、图片或 PDF/不调用外部模型”。
- [ ] 只能从内置案例里选，没有输入框、没有上传按钮。
- [ ] 载入后显示七阶段 DNA、来源证据、卖什么/谁付钱/如何交付/风险边界。
- [ ] 保存到本机、查看完整案例、进入画布可用。
- 高风险：审核员可能按“生成式 AI”类目来查；页面必须 0 输入口。
- 现状：☑ 达标（`pages/ai/ai.wxml`）。

### Step 5 · 画布 Tab

- [ ] 能加/减模块；节点可点开看详情；实时验算数字合理。
- [ ] “环节覆盖不代表盈利概率”“成本未逐节点核算”提示可见。
- [ ] 保存方案、生成验证方案可用。
- [ ] 重置画布有二次确认（如无，建议加，防误删）。
- 高风险：若“验证方案”读起来像“创业指导/投资建议”，需在方案页加“仅为自检清单，不构成经营建议”。
- 现状：⚠️ 需确认验证方案页有免责提示【需核实】。

### Step 6 · 我的 Tab

- [ ] 不显示未登录头像/昵称（当前显示“本机档案”+“Q”字母，合规）。
- [ ] 收藏/演示记录/方案入口可用，空态友好。
- [ ] “100 条案例全部免费阅读/无会员购买/无订单/无外部模型/广告未启用”可见。
- [ ] “隐私与权限”“帮助中心”“关于”可打开。
- [ ] “分享小程序”可用。
- 高风险：`profile.js:25` `wx.openSetting` 失败提示“请在微信设置中管理权限”——本版无权限可管理，可能被问“管理什么权限”；建议改为“本版无需额外授权”。
- 现状：⚠️ 文案微调。

### Step 7 · 法律三页 + 关于页

- [ ] 隐私保护指引：9 节齐全；第 07 节联系方式**已有真实邮箱**（当前是“待配置”）；版本/日期与后台一致。
- [ ] 用户协议：服务内容写明“不提供内容生成、交易撮合、投资顾问、付费会员、订单或支付”。
- [ ] 未成年人保护说明：可打开；写明监护指导与现实经营限制。
- [ ] 关于页：主体名称、备案号、版本号、联系方式齐全（当前只有品牌/版本 0.1.0）。
- 高风险：**三页任一出现“待配置/示例邮箱/0.1.0”都会被追问**。
- 现状：❌ 邮箱待配置、备案/主体待补、版本号待改。

### Step 8 · 分享与朋友圈

- [ ] 首页/详情/我的分享卡片标题客观、无水印诱导。
- [ ] 详情页分享朋友圈入口是否存在（当前详情页无 `onShareTimeline`）→ 审核一般不因此拒，但运营缺失。
- [ ] 从分享卡片进入后能正常返回首页。

### Step 9 · 断网与异常

- [ ] 飞行模式冷启动：预置案例可读，无“网络错误”弹窗。
- [ ] 清除缓存后首次进入不崩。
- [ ] 快速连点按钮不重复跳转/不崩。
- [ ] 返回键在各页行为一致。

### Step 10 · 权限与合规抽查

- [ ] 不申请位置/相册/麦克风/通讯录/手机号。
- [ ] 无“分享后解锁/关注领资料”。
- [ ] 无外部跳转（web-view/业务域名）——本版没有 web-view。
- [ ] 无广告组件实际渲染。
- [ ] 无“测试数据/示例数据”字样。

## 3. 审核员最可能问的 20 个问题 + 标准回答

| # | 问题 | 建议回答（依据见括号） |
|---|---|---|
| 1 | 这个小程序是做什么的？ | 商业案例结构化阅读工具：把 100 条公开商业案例拆成七阶段与资产卡，供用户学习与自我验证；全部免费、无需登录。（简介/关于页） |
| 2 | 有没有 AI 生成？为什么第三个 Tab 在“案例演示”位置？ | 没有。该 Tab 是“案例演示”，只读取安装包内预置案例，不接收输入、不调用任何外部模型，页面已明示。（`pages/ai/ai.wxml`） |
| 3 | 案例内容从哪来？是否侵权？ | 来自可公开访问的官方/公开页面，详情页逐条展示来源链接、发布方与核对日期；我们只做结构化编辑分析，不使用他人 logo/截图，已声明第三方权利归属。 |
| 4 | 有没有交易、付费、会员、订单？ | 全部没有。100 条案例全免费；无订单、无支付、无会员入口，代码中未接入支付。 |
| 5 | 有没有用户上传/发布内容？ | 没有。不接收文字、网页、图片、PDF；无评论、无社区、无 UGC。 |
| 6 | 收集了哪些个人信息？ | 不收集账号信息；仅在本机缓存收藏/画布/方案；启动时读设备性能等级与窗口信息用于画面降级，不保存、不上传；可一键清除。（隐私页第 03/06 节） |
| 7 | 为什么第一次打开有隐私提示？ | 告知本机数据用途与清除方式；本版不调用需要授权的隐私接口，提示仅作说明，可关闭；后台隐私保护指引与页面一致。（`privacy-popup`） |
| 8 | 未成年人能用吗？有什么保护？ | 可在监护人指导下学习；不提供现实经营、借贷、投资、收付款指令；不要求登录、不收集未成年人信息；有《未成年人保护说明》页。 |
| 9 | 案例里的价格/收入数字是收益承诺吗？ | 不是。展示的是来源页面可见的价格/成本信息，不代表收益；每个案例标注“公开信息≠审计过的成交/利润”，我们不承诺结果。 |
| 10 | 有没有投资建议？ | 没有金融类目与投资建议；不推荐任何投资标的，不提供回报判断。 |
| 11 | 为什么选这个服务类目？ | 功能是信息查询/学习工具，不是教育培训、不卖课、无资质要求；类目对应页面可从首页 2 次点击内到达。 |
| 12 | 有没有客服/联系方式？ | 有联系邮箱（提审前填入真实邮箱）；后续会开通小程序客服；隐私页与协议页均公示。 |
| 13 | 备案号在哪？ | 上线后由平台在小程序“更多资料”页展示；同时“关于”页会展示主体名称与备案号（以平台为准）。 |
| 14 | 为什么没有登录？ | 本机记录不需要账号，符合最小必要；避免收集非必要个人信息。 |
| 15 | 数据会丢吗？ | 可能。清理缓存/换设备会丢失，已在协议与隐私页明确提示，不承诺同步或恢复。 |
| 16 | 有广告吗？ | 未启用，无广告位、无广告组件渲染。 |
| 17 | 3D 画面会不会卡？ | 系统按设备性能自动降级（减少粒子/切换轻量渲染），低性能设备有降级路径。 |
| 18 | 内容会不会引导用户创业赚钱？ | 定位是学习与验证思路，不承诺收益、不提供项目推荐；如审核认为个别文案有引导，可立即弱化（见第 5 节）。 |
| 19 | 分享到朋友圈？ | 首页支持；朋友圈打开为单页模式，有官方限制，我们已按限制设计入口。 |
| 20 | 内容过时/有错误怎么办？ | 每条标注核对日期，季度复核；可通过公示邮箱反馈，48 小时内响应。 |

## 6. 一票否决清单（任一未过，不要提审）

- [ ] 后台隐私保护指引未配置，或与小程序内不一致。
- [ ] 支持邮箱仍为空/占位（`@example.com`）。
- [ ] 备案号、主体名称缺失且关于页/后台无任何主体信息。
- [ ] 服务类目选了“教育服务”等需资质类目但无资质。
- [ ] 页面存在“稳赚/月入/轻松赚钱/保证收益”等收益承诺（当前 grep 为 0，需保持）。
- [ ] 任一 Tab 打开白屏、报错、按钮无响应。
- [ ] 审核截图与真实页面不一致（P 图、浏览器预览图）。
- [ ] 名称/头像/简介三者不一致或名称有商标风险。
- [ ] 测试路径写不清，审核员找不到核心功能。
- [ ] 基础库版本冲突（3.12.0 vs 3.17.4）未统一。
- [ ] AppID 与备案/认证主体不一致。
