# 2.0 体验版新手引导交付

用户确认 1.0 为已上线版、2.0 为体验版。本轮完成本地 2.0 工程中的新手引导，不修改微信线上 1.0。

## 使用流程

- 首次进入首页，现有隐私提示被用户接受之后显示新手引导提示。
- 可观看，也可跳过；选择保存在本机，新手提示不会每次弹出。存储失败时仍在当前会话避免重复提示。
- 在“我的”首个菜单“新手引导”随时重看。
- 视频手动播放，保留原生控件；离页暂停，随时跳过或返回。
- 文字步骤始终可读，视频读取或播放失败可重试，也可直接开始低成本案例。
- 指引为：选案例、看懂做法、加入画布、写验证方案。进入教程不会写入案例或验证业务记录。
